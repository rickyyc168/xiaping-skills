## 课程覆盖

| 模块 | 讲次 | 核心主题 |
|------|------|----------|
| 基础原理 | 01-03 | 供需关系、分工交易、理性与欲望 |
| 个人决策 | 04-06 | 机会成本、保险、投资风险 |
| 企业市场 | 07-10 | 创新、激励、治理、行为经济学 |
| 市场制度 | 11-15 | 博弈论、竞争、公平、失灵、政府 |
| 转型发展 | 16-20 | 体制转型、道德、消费、教育、增长 |
| 高级专题 | 21-30 | 城市化、贸易、周期、通胀、财政、思维方式 |
