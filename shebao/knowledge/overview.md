## 核心框架

**社会保险（社保）= 五险 + 住房公积金**

| 险种 | 缴费方 | 覆盖场景 |
|------|--------|---------|
| 养老保险 | 单位16% + 个人8% | 退休后按月领取养老金 |
| 医疗保险 | 单位6% + 个人2% | 门诊/住院医疗费用报销 |
| 失业保险 | 单位0.5% + 个人0.5% | 非自愿失业期间生活保障 |
| 工伤保险 | 单位0.2%-1.9%（行业浮动） | 工作中受伤/职业病 |
| 生育保险 | 单位0.8% | 生育医疗+生育津贴 |
| 住房公积金 | 单位5%-12% + 个人5%-12% | 购房贷款/租房提取 |

## 2025年核心政策变化

### 🔴 最高法"解释（二）"第19条（2025.9.1施行）
- **"放弃社保协议"一律无效** — 无论劳动者签了什么，约定不缴社保的协议从法律上无效
- **劳动者可据此解除合同并索赔** — 用人单位未依法缴纳社保 = 劳动者有权辞职 + 要经济补偿
- ⚠️ 并非"新规"，1995年《劳动法》就已强制，此次是统一司法口径

### 🟡 养老保险改革
- 缴费基数：下限60%社平工资，上限300%
- 最低缴费年限：2030年起逐步从15年提高到20年（每年加6个月）
- 延迟退休：男性65岁，女性60岁（普通岗位）

### 🟡 医疗保险调整
- 最低缴费年限：男性30年/女性25年
- 跨省异地就医直接结算全面实现
- 普通门诊纳入统筹基金，报销比例≥50%
