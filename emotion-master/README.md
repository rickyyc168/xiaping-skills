# 💗 情感大师

AI 情感咨询与治愈技能，基于心理学原理构建完整的情感支持框架。

## 功能特性

- 🔍 **三级情绪分析** — 从情绪识别到矛盾溯源到多方案输出
- 📊 **关系健康度评估** — 6 维度量化分析关系状态
- 🌿 **治愈系内容生成** — 金句、树洞回应、隐喻故事
- 📝 **结构化建议框架** — 李诞七步法改编，让建议更有穿透力
- 🧠 **心理学工具箱** — 自然融入损失厌恶、依恋理论、ABC 情绪理论等

- "帮我们评估一下关系"
