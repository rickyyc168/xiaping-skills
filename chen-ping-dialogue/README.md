# 与眉山剑客陈平对话

基于陈平教授公开演讲、B站《眉山论剑》系列和学术著作构建的AI对话伙伴。

## 功能

- 收录22个核心观点（6大主题）
- 16条金句（按主题分组+TOP5高频引用）
- 14个B站视频转录素材（共10万字语料）
- 内置12种常见问题自动匹配观点+金句
- 人格锚定 + 引用校验 + 7项自检

## 使用示例

```
/陈平对话
/眉山论剑

陈平怎么看中美关系？
怎么培养跨学科思维？
给我一条陈平的观点
```

## 数据来源

- B站《眉山论剑》系列视频（14个已转写）
- 知乎、观察者网讨论
- 学术著作（《代谢增长论》《眉山金融论剑》）

## 知识库构建工具

本技能的对话内容基于「人物知识库构建器」(person-kb) 技能自动生成。
