# 百度网盘AI笔记知识库构建器 v2

输入百度网盘AI笔记分享链接，自动提取内容构建结构化课程知识库。

## v2 优化亮点

| 优化项 | v1 | v2 | 提升 |
|--------|----|----|------|
| 浏览器 | 每链接开关一次 | 全程复用 session | -3s/链接 |
| 等待策略 | 固定 8s | 智能检测 3-5s | -4s/链接 |
| 去重 | 无 | URL + hash 双重去重 | 避免重复 |
| 缓存 | 无 | 原始文本缓存 | 支持重新结构化 |
| 进度 | 无 | progress.json | 断点续跑 |

## 触发词

笔记知识库、建知识库、提取笔记、网盘笔记、AI笔记提取、课程笔记

## 使用方式

发送百度网盘AI笔记分享链接即可，支持批量：

```
帮我提取这个笔记 https://pan.baidu.com/fcb/s?share_uk=xxx&share_id=xxx
```

## 依赖

- browser 工具（浏览器自动化）
- 零外部依赖，开箱即用
