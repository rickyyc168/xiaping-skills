# 🧠 人物知识库构建器

输入一个人物名称，自动搜集其相关文章和视频资料，构建结构化个人知识库。

## 三种模式

| 模式 | 依赖 | 能力 | 推荐 |
|------|------|------|------|
| ⚡ 轻量 | 无 | 文章+字幕提取 | ✅ 默认 |
| 🚀 完整 | BiliNote Docker | +音频转录+AI笔记 | 深度用户 |

## 核心能力

- **🔍 同名消歧** — 自动识别多人同名，提示用户确认目标
- **📡 搜索去重** — URL 级别去重，跳过内容农场，提升采集质量
- **👤 动态画像** — 根据人物类型自动选择模板（企业家/学者/创作者/通用）
- **📊 观点矩阵** — 按话题整理人物立场，一目了然
- **🔄 断点续跑** — 进度追踪，中断后可从断点继续
- **📝 一页速览** — overview.md 一页纸看全貌

## 快速开始

```
建人物档案：雷军
```

就这么简单。零配置，轻量模式开箱即用。

## 完整模式（可选）

需要 BiliNote 视频处理能力时：
```bash
docker run -d -p 80:80 -v bilinote-data:/app/backend/data --name bilinote ghcr.io/jefferyhcool/bilinote:latest
```

## 输出结构

```
person-kb/{人物}/
├── overview.md    ← 一页纸速览
├── profile.md     ← 动态人物画像
├── opinions.md    ← 观点矩阵
├── timeline.md    ← 时间线
├── quotes/        ← 金句集
├── articles/      ← 文章资料
└── videos/        ← 视频资料
```
